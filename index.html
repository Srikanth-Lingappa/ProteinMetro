What this is

ProteinMetro — a subway-map route advisor for protein design pipelines

Answer a few questions about what you're designing, what you know about your target, and what compute and validation you have — the app recommends a real pipeline of tools for your case, styled as a subway route. Each stop is a real, named tool; each line color is a design use-case (binder design, enzyme design, antibody design, and so on).

Recommendations come from an underlying expert-rule engine: your answers are matched against tool capabilities and a set of scientific rules, which rank the candidates and build the route. Click any station or the connecting line between two stations for details on that tool or that handoff.

Station types

Regular station — a tool used for one specific job in the pipeline (e.g. a docking step).
Transfer station — a versatile tool that shows up across many different design pipelines (e.g. AlphaFold2, used for structure prediction almost everywhere).

Reading the top row

The pills across the top are the different design "lines" (use-cases) this map covers. The ones lit up are the lines your current recommended route actually touches; the rest are dimmed.

About

ProteinMetro is an extension of the protein-design-subway-map project, which provides the underlying map of tools and pipelines. Recommendations are guidance based on encoded expert rules — always check each tool's own documentation before relying on a route.

Use of AI: the code for this tool was written by an AI model (Claude, by Anthropic). The design, the tool coverage and the expert rules were directed by the author.
